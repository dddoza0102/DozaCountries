необходимые плагины для запуска:
   worldguard-bukkit 7.0.16/
плагин работает на версии 1.21.11
java 21
команды плагина:
  /country create <название гос-ва> <ник президента> - команда на создание государства
  /country add <название гос-ва> <ник игрока> - команда на добавление в государство определнного игрока
  /country setflag <название гос-ва> - установить флаг с узором для дальнейшего привата территорий
разрешения плагина:
  dozacountries.command
[!] примечание: все действия производятся от лица администрации или игорков имеющих права на управление государствами на сервере. Не стоит выдавать права
обычным игрокам учавствующим в игровом процессе
для своих репозиторий к плагину:
         <dependency>
            <groupId>dev.doza</groupId>
            <artifactId>dozacountres</artifactId>
            <version>1.0.0</version>
            <scope>provided</scope>
        </dependency>
